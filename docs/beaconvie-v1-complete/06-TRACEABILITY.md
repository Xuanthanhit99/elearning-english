## Open decisions (not silently assumed)
- Exact V1 release languages/content depth and reviewed course coverage.
- AI provider/cost limits and benchmark rubric per language.
- Payment provider, legal/tax obligations, payout and refund rules.
- Native store billing compliance and Android/iOS release accounts.
- Real existing code/module/route statuses; schema-only inspection insufficient.
- SEO Search Console and analytics access; user count definition.
- Approved exact master images and UI spec assets.
- Actual team capacity and feasible delivery estimate.

## Change control
Any material scope change updates this baseline, traceability and PR dependencies. Feature flags protect incomplete flows. No merge/deploy without explicit release gates.
